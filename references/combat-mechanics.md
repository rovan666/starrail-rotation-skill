# 战斗机制公式速查

本文件是模拟与排轴的全部公式依据。引用外部社区公式（KeqingMains 等）并与游戏内表现核对过；版本更新导致公式变动时优先以游戏实测为准。

## 行动条（Action Gauge）

- 基础行动值：`Base AV = 10000 / 速度`
- 单位从 0 开始积累行动值，先到 10000 者行动（等价于跑完自己一圈）。
- 行动后 AV 归零重新积累。**同 AV 同时到达终点时，我方角色按站位顺序优先于敌方**。
- 拉条/推条：`新行动值 = max(0, 当前AV - 10000 × (提前% - 延后%))`，注意拉条作用于"当前剩余行动值"，不是最大行动值——拉得越晚收益越小。
- 变速：`新AV = 当前AV × 原速度 / 新速度`。
- 变速与拉条同时存在时，先结算行动值变化再比较顺序（游戏内拉条到 0 的角色优先于变速到 0 的角色，如风套大招拉条优先于舞舞舞）。
- 回合（轮）边界：忘却之庭等以 150 AV 为一轮（0T 指第一轮 150 AV 内结束）。

| 速度 | 行动收益 |
|---|---|
| 120 | 2 轮 3 动 / 7 轮 9 动 |
| 134 | 1 轮 2 动 / 4 轮 6 动 / 7 轮 10 动 |
| 143 | 3 轮 5 动 |
| 146 | 5 轮 8 动 |
| 156 | 4 轮 7 动 |
| 160 | 2 轮 4 动 |
| 172 | 3 轮 6 动 / 5 轮 9 动 |

用法：先按目标轮数反推全队需要的行动次数，再查表定速度下限；辅助速度超出阈值的部分是浪费，可降速换其他属性。

## 削韧与弱点击破

**削韧基础值**（普攻 = 1）：

| 攻击类型 | 削韧 |
|---|---|
| 单攻战技 | 2 |
| 群攻战技 | 1（对每个敌人） |
| 单攻终结技 | 3 |
| 群攻终结技 | 2（对每个敌人） |
| 扩散类：中心 / 相邻 | 2 / 1（战技、强化普攻） |
| 扩散类终结技：中心 / 相邻 | 2 / 2 |
| 普攻、追加攻击 | 1 |
| 弹射类 | 每段按技能设定 |

削韧值 = 基础值 × 削韧增益。非弱点属性攻击不削韧。

**击破触发**：韧性条清零 → 击破伤害 + 强制行动延后 + 属性异常 + 解除 10% 减伤并施加 10% 易伤。

**属性击破效果**：

| 属性 | 效果 |
|---|---|
| 物理 | 裂伤（持续物伤 2 回合）+ 延后 25%，击破倍率 4×（最高档） |
| 火 | 灼烧（持续火伤 2 回合）+ 延后 25%，倍率 4× |
| 风 | 风化（持续风伤 2 回合），倍率 3× |
| 雷 | 触电（持续雷伤 2 回合）+ 延后 25%，倍率 2× |
| 冰 | 冻结：跳过 1 回合，解冻时受冰伤 + 解冻延后 50%，倍率 2× |
| 虚数 | 禁锢：延后 30% ×（1+击破特攻）+ 减速 10%，倍率 1× |
| 量子 | 纠缠：延后 20% ×（1+击破特攻）+ 每回合开始量伤，攻击叠层最多 5 层，倍率 1× |

击破伤害公式：`击破伤害 = 等级基数 × 属性倍率 × 韧性系数 × (1 + 击破特攻) × 易伤 × 抗性 × 防御 × 减伤`。等级基数只与角色等级有关（80 级约 3767），**与攻击力无关**——击破流不需要堆攻击。

## 伤害公式（期望值）

直伤：`伤害 = 攻击区 × 倍率 × (1+增伤+属性伤害加成) × 防御乘区 × 抗性乘区 × (1+易伤) × (1+减伤) × 暴击期望`

- 防御乘区：己方打敌方 `100/(100+受击方防御×(1-减防)×(1-无视防御))` 近似处理，减防收益随数值递增（反向稀释）。
- 抗性乘区：敌方抗性 20%（无弱点时）/ 10%（有弱点未破）/ 0%（弱点已破后抗性 -20% 区域另算），抗性穿透直接扣减。
- 暴击期望：`1 + 暴击率 × 暴击伤害`（期望口径，排轴不受暴击随机影响）。
- **持续伤害（DoT）与击破伤害不吃暴击、不吃增伤区外的部分增益**；DoT 吃攻击、增伤、易伤、减防、抗性。
- 有韧性时目标受伤 ×0.9；击破后受伤 ×1.1。

## 能量

- 普攻回能 20；战技回能 30；终结技回能 5；受击按攻击段数回能（单体一段约 10~15，按技能设定）；击杀回 10；光锥/遗器/天赋另算。
- 终结技满能量后可在**任意决策点插队**释放，释放时机是排轴的核心自由度。
- 能量恢复效率 ×（1+效率）作用于全部回能。

## 战技点

- 进战 3 点，上限 5。普攻 +1（强化普攻角色不回），战技 −1（部分角色例外按数据文件标注）。
- 全队共享，模拟中每一动必须做收支对账。

## buff/debuff 持续与结算

- 持续 N 回合 = 从施加者的下一回合开始数 N 个**持有者回合**；回合开始触发的效果在持有者回合开始时结算。
- 排轴检查点：主 C 的每个爆发窗口内，增伤/减防/易伤是否全覆盖；覆盖不全的 buff 要么提前挂，要么让主 C 调速对齐。

## 欢愉体系（笑点 / 阿哈时刻 / 欢愉技）

- **笑点**：全队共享资源，欢愉角色的技能（战技/终结技/结界等）按数据文件标注产出。笑点本身不进能量循环。
- **阿哈时刻**：行动轴上存在星神「阿哈」（纯跑条单位，速度由基础值+欢愉角色速度决定）。轮到阿哈行动时触发阿哈时刻：队伍中欢愉角色按**参演编号**（越小越先，如爻光 116、火花 144、银狼LV.999 为 999）依次施放各自的**欢愉技**。欢愉技是独立于普攻/战技/终结技的第五技能（上游类型码 `ElationDamage`）。
- **欢愉伤害公式**：`欢愉伤害 = 等级基础值 × 倍率 × (1+欢愉度) × (1+增笑度) × (1 + 5×笑点/(笑点+240)) × 双暴 × 易伤 × 减防 × 抗性穿透 × 减伤`。**不吃攻击力与伤害提高**；排轴时欢愉角色面板只关心速度/双暴/欢愉度/穿透。
- **好活当赏**：阿哈时刻后为参演欢愉角色提供增益（计入本次笑点，持续 2 持有者回合，多个独立计时合并计笑点）；欢愉角色的普攻/战技在此状态下附带欢愉伤害，是平时输出的主要来源。
- 排轴要点：阿哈时刻是欢愉队的爆发窗口，终结技/耗点动作应尽量排在阿哈行动前后，使欢愉技吃到最高笑点；爻光终结技可让阿哈立即多跑一个固定 20 笑点的回合，是调轴的核心手段。

## 特殊机制备忘

- 翁瓦克：进战首动行动值提前 40%（仅第一面）。
- 舞！舞！舞！：装备者释放终结技后全队拉条 16%/18%/20%/22%/24%（按叠影）。
- 风套（晨昏交界的翔鹰）：装备者终结技后自身拉条 25%，且优先于舞舞舞结算。
- 冻结、禁锢、纠缠、推条类效果的实质都是修改行动值。
- 敌人"转面"（波次切换）：行动值从 0 重新计算，回能与部分状态保留——排轴必须分面进行。
- 锁弱点/无敌阶段敌人不可削韧，排轴时把削韧资源留到弱点恢复后。
