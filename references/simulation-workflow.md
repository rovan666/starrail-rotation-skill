# 战斗模拟协议

模拟目标：给出可复现的完整行动轴。精度要求：行动顺序、破韧时机、能量循环、战技点收支必须逐项正确；伤害按期望值。

## 目录

- 状态定义
- 模拟主循环
- 逐动记录格式

- 多面/波次处理

## 状态定义

模拟开始时初始化：

- 时间轴：全局 AV 计时器（非必需，主要用于报告展示）；每个单位维护 `自身进度 = 已积累AV`，满 10000 行动。
- 每个我方角色：`速度、能量(0)、buff列表[{名称, 剩余持有者回合, 效果}]、面板`。
- 每个敌人：`速度、韧性(当前/最大)、弱点列表、debuff列表、血量(用于伤害是否够的粗判)`。
- 全局：`战技点(3/5)、当前波次/面、行动计数`。
- 回合边界记录：150 AV 刻度，用于判断 T 数。

## 模拟主循环

1. 计算所有单位下一次行动时间（剩余 AV ÷ 速度）。
2. 取最近的单位行动；结算其回合开始效果（DoT、冻结解冻、buff 回合数 −1 到期的移除）。
3. 该单位行动：按排轴决策表选择动作（普攻/战技/终结技），结算：伤害（期望）→ 削韧（检查是否触发击破，触发则结算击破伤害+延后+异常+易伤）→ 回能 → 战技点收支 → 施加/刷新 buff 与 debuff。
4. 终结技判定：能量满的角色进入"可插队"状态。在每个决策点（任意单位行动前后）检查是否存在更优释放时机，记录选择理由。
5. 敌人行动：按其技能表执行（单体/群攻/蓄力/召唤），结算我方受击回能、护盾/治疗压力。
6. 敌人死亡：结算击杀回能，波次切换检查。
7. 回到 1，直到目标达成（全灭/轮次超限判定失败）。

## 逐动记录格式

每一动一行，字段：

`[序号] 单位 | 行动类型 | 战技点(前→后) | 能量(前→后) | 削韧(目标:值, 剩余韧性) | 触发事件(击破/击杀/插队在第几动) | 备注(buff覆盖情况)`

## 终结技插点位规则

按优先级评估插队时机：

1. **打断**：敌人蓄力高威胁技能且其行动前能量刚好够 → 必插。
2. **破韧窗口**：插队终结技可恰好击破关键敌人（抢易伤窗口）→ 优先。
3. **buff 覆盖**：终结技伤害/buff 能完整覆盖主 C 后续爆发 → 提前插。
4. **能量溢出**：继续普攻/战技将浪费回能（能量已满仍获得回能）→ 立刻插。
5. 默认：攒到主 C 行动前插。

## 校验点

- 每 5 动核对一次：行动序列与行动条预览一致（剩余 AV ÷ 速度排序无矛盾）。
- 每次削韧后核对韧性条 ≥ 0，击破当动结算延后。
- 每次行动后战技点 ∈ [0,5]；不足时该方案作废，回溯调整产点位。
- buff 施加时检查：主 C 下一次 N 动是否全覆盖；不覆盖则调整施加时机或标注损失。
- 破韧时机：记录每次击破的全局 AV 位置，确认与排轴意图一致（如"在 Boss 蓄力前击破"）。
- 能量：每个终结技释放前能量 ≥ 上限；释放后从 0（或按数据文件的保留值）重计。

## 多面/波次处理

- 转面时：我方行动值重新从 0 开始（保留速度变化），能量保留， buff/debuff 按剩余持有者回合保留；翁瓦克仅第一面生效。
- 分面输出排轴：每面独立编号（一面第 1 动、二面第 1 动……）。
- 虚构叙事等多波次：敌人逐个补充，削韧资源分配按"先破关键怪"原则。

## 失败回退

- 轮次内打不完 → 分析伤害缺口（期望值口径）→ 回退方案：降速换输出词条 / 调整爆发窗口对齐易伤 / 更换削韧属性。每次只改一个变量再重跑，报告记录对比。
- 战技点崩 → 优先把非关键动从战技改普攻，其次调整辅助速度错峰产点。
